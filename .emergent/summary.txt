**Key Technical Concepts**
- **Conditional Feature Rendering**: Using feature flags (, ) fetched from the backend to conditionally render UI components (Admin tabs).
- **Bulk Operations**: Implementing a select all and multi-select UI to perform a bulk action (delete) via a single API call.
- **Client-Side State Hydration**: Diagnosing and fixing issues related to Zustand's persisted state being stale on page navigation, ensuring components always have the latest user data.
